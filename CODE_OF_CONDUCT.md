# Code of Conduct

We want this project to be a respectful place for learners, researchers,
maintainers, and contributors with different levels of experience.

Be constructive, specific, and patient. Critique ideas and code rather than
people. Do not harass, threaten, discriminate, publish another person's private
information, or use sexualized language or attention. Assume good faith while
still taking reported harm seriously.

Maintainers may edit or remove contributions and communications that violate
these expectations, and may temporarily or permanently restrict participation.
Report conduct problems privately to the repository owner. Reports will be
handled with discretion, with conflicts of interest delegated when possible.

This policy applies in project spaces and when someone is officially
representing the project.
