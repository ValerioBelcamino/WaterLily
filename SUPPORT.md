# Support

Use GitHub Discussions for setup questions, design exploration, and usage help
once Discussions is enabled. Until then, open a question issue with sanitized
configuration, platform and Node versions, and the smallest reproducible case.

Use the bug report form for reproducible defects and the feature request form
for product proposals. Never include API keys, private conversations, `.env`
contents, or SQLite databases. Security vulnerabilities follow
[`SECURITY.md`](SECURITY.md) instead of the public tracker.

The project is an early public alpha maintained on a best-effort basis; there is
currently no guaranteed response time or commercial support channel.
