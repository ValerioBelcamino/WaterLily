# WaterLily desktop icon

The original WaterLily mark combines a water-lily silhouette with three graph
nodes. It was generated for this project with OpenAI's built-in image-generation
tool, then validated for transparent edges and resized locally.

- `icon.png`: Linux and source-resolution icon (1024 × 1024 RGBA).
- `icon.ico`: Windows multi-resolution icon (16–256 px).
- `icon.icns`: macOS icon family.

The icon is distributed under the repository's Apache-2.0 license.
